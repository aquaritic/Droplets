 A website where the key you press on your keyboard creates a droplet and determines where and what kind of color it will spawn in with. There also buttons to activate some different kinds of modes like bubble mode which will reverse the gravity making the droplets go upwards instead of downwards. 
 Example: First half of alphabet (like a) will create droplets on the left side, whereas z (the end of the alphabet) will create droplets on the right hand side. Uppercase letters will make droplets that are dark blue, clicking the buttons I made will allow you to add twists to the droplets you type in and change the background color.
